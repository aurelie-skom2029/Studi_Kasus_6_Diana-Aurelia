Fitur Program :<br>
• Melihat semua data nilai mahasiswa<br>
• Menambahkan data nilai baru<br>
• Keluar dari program<br>
• Validasi pilihan menu<br>

Data yang Digunakan :<br>
• Nama Mahasiswa<br>
• NIM<br>
• Mata Kuliah<br>
• Nilai<br>

Konsep Python yang Digunakan :<br>
• Library (json)<br>
• While Loop<br>
• For Loop<br>
• If, Elif, dan Else<br>
• Input dan Output<br>
• List<br>
• Dictionary
<br>
• File Handling (membaca dan menulis file)
<br>
• Try dan Except
<br>

Penjelasan Bagian Kode :
<br>
• import json, dipakai untuk membaca dan menyimpan data ke file
<br>
• nama_file, menyimpan lokasi file tempat data disimpan
<br>
• while True, membuat menu muncul terus sampai user memilih keluar
<br>
• try/except, mencegah error saat file belum ada
<br>
• json.load membaca isi file JSON menjadi list
<br>
• for, menampilkan data mahasiswa satu per satu
<br>
• append, menambahkan data baru ke dalam list
<br>
• json.dump, menyimpan list ke file JSON
<br>
• break, menghentikan program saat memilih menu keluar. 
<br>

<br>
